# eLISAschool — PWA de Gestion Scolaire

Application modulaire multi-tenant pour la gestion avancée d'établissements scolaires en Afrique subsaharienne (Cameroun).

**Stack** : React 19 + Vite, Node.js + Express + TypeORM, PostgreSQL (RLS), Docker.

**Modules** : Élèves, notes, bulletins, EDT, paie, personnel, organigramme, finances, absences, examens nationaux, portail parents.

**Bilingue** FR/EN — RBAC granulaire — Architecture monorepo.
