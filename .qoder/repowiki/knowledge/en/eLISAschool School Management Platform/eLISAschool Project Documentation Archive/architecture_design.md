Flat Markdown-only repository with no build tooling; navigation is centralized in `INDEX.md` which catalogs ~400 documents across 15 thematic directories (`analyses/`, `corrections/`, `implementations/`, `guides/`, `rapports/`, `syntheses/`, `resumes/`, `audits/`, `certifications/`, `checklists/`, `configurations/`, `deploiements/`, `migrations/`, `ameliorations/`, `autres/`). Root-level reference files (`technical.md`, `rbac-system.md`, `user-guide.fr.md`, `CONVENTIONS-PERMISSIONS.md`, `PERMISSIONS-BASE-DONNEES.md`) provide cross-cutting entry points. The `autres/_*` subdirectories group ephemeral or legacy artifacts (sessions, fixes, quick-starts, multi-tenant notes) under underscore-prefixed buckets to keep them out of the main index. Dependency direction is one-way: documents are authored outputs referencing source code elsewhere in the repo; this module has no runtime dependencies on application code.
