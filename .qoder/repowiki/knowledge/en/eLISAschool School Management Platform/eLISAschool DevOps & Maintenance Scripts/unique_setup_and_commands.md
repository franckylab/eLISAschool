Scripts assume the repo root layout `backend/`, `frontend/`, `docker/` and a `.env` file at the project root. The canonical full bootstrap is `./scripts/deploy-complet.sh`, which expects a running `elisaschool_db` container (port 7002) and `pg_dump` on PATH. For local dev only, `./scripts/start-dev.sh [--backend|--frontend|--all]` starts everything and writes PIDs to `/tmp/elisaschool-{backend,frontend}.pid`.
