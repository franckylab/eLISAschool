- **Configuration-Driven Behavior**: All four child modules (clubs, gamification, messagerie, notifications) rely on a shared `@modules/configuration/utils/config.helper` to enforce dynamic business rules (e.g., enrollment limits, point values, message length, notification channels) rather than hard-coded constants.
- **Shared Infrastructure Contracts**: Each module utilizes a common `AppDataSource` for TypeORM persistence, `@common/filters/error.filter` for standardized error handling, and `@common/utils/logger.util` for consistent observability.
- **Decoupled Module Pattern**: Modules are isolated via independent Express routers and services, with no direct cross-module imports, ensuring that engagement features remain loosely coupled while sharing the same underlying platform utilities.
