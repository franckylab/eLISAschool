- **Shared Entity Core**: The `auth` module acts as the central data hub, owning core entities (`Utilisateur`, `Role`, `Permission`, `AuditLog`) that are directly imported and used by `utilisateurs`, `rbac`, and `audit` modules, creating a tight coupling on the `auth` domain model.
- **Cross-Module Service Wiring**: `utilisateurs` and `rbac` explicitly depend on `auth` services (`auditService` for logging, `permissionResolverService` for cache invalidation) to maintain consistency in security state and audit trails without direct database manipulation.
- **Centralized Permission Resolution**: A singleton `permissionResolverService` in `auth` manages an in-memory cache for permissions, which is invalidated by `rbac` upon role/permission changes, ensuring real-time authorization updates across the system.
- **Unified Audit Strategy**: All modules funnel security-relevant events into a single `AuditService` located in `auth`, which standardizes log structure, severity, and IP capture before persisting to the shared `AuditLog` entity.
