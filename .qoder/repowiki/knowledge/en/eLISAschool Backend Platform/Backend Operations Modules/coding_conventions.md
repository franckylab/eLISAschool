- Controllers define routes using Express Router, attach `authMiddleware` globally or per-route, apply role guards (`requireRoles`, `staffOnly`, `managerOnly`) selectively, validate input with `validateDto(schema, req.body)`, delegate to service methods, and wrap responses in `{ success: true, data: ... }` envelopes with try/catch forwarding to `next(error)`.
- Services are exported as both a named class (for instantiation) and a singleton instance (`export const xxxService = new XxxService()`); they inject TypeORM repositories via `AppDataSource.getRepository(Entity)` in constructors and throw `AppError` with HTTP status codes and error codes for business rule violations.
- DTOs use Zod schemas suffixed with `Schema` (e.g., `createPersonnelSchema`) for validation and derive TypeScript types via `z.infer`; update schemas are created by calling `.partial().omit()` on create schemas to enforce field restrictions.
- Entities use TypeORM decorators with UUID primary generators (`@PrimaryGeneratedColumn('uuid')`), include `@CreateDateColumn` and `@UpdateDateColumn` timestamps, define multi-tenancy via `etablissementId` columns with `@ManyToOne` relations to `Etablissement`, and add `@Index` decorators on foreign key columns for query performance.
