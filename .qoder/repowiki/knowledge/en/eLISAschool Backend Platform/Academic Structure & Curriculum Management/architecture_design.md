- Five independent sub-modules (annees-scolaires, cycles, niveaux, periodes, matieres), each following a strict four-layer structure: controllers (Express Router), services (TypeORM repository access), entities (TypeORM decorators), and DTOs (Zod schemas).
- Each sub-module exports through a flat index.ts that re-exports entities, dto, services, and controllers.
- Controllers apply authMiddleware universally and requireRoles(Role.ADMIN, Role.SUPER_ADMIN) on all mutation endpoints; responses follow a uniform { success, data/message } envelope.
- Services obtain TypeORM repositories via AppDataSource.getRepository() in their constructor and implement async CRUD operations with domain-specific business rules (e.g., deactivating other active school years, preventing deletion of closed periods, enforcing subject-program constraints).
- Entities use UUID primary keys, TypeORM @ManyToOne/@JoinColumn for cross-entity relationships, and @Index annotations for query performance. The matieres sub-module is the most complex, containing four entity types (Matiere, GroupeMatiere, MatiereNiveau, AffectationMatiere) and cross-module dependencies on annees-scolaires and classes services.
