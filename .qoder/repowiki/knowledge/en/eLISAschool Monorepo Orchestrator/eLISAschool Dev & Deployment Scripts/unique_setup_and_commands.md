All scripts must be made executable once: `chmod +x scripts/*.sh`. The canonical full bootstrap is `./scripts/deploy-complet.sh`, which expects a running `elisaschool_db` container and runs every `*.sql` migration found under `backend/database/migrations/` in filesystem order. Development mode is `./scripts/start-dev.sh [--backend|--frontend|--all]`; health checks poll `http://localhost:3001/api/health` and `http://localhost:5173` before declaring ready.
