Seed runner (`src/database/seeds/run-seeds.ts`) loads `.env` from `../../../../.env` relative to itself and constructs a separate `DataSource` with `synchronize: true` and an entity glob pointing at `../../modules/**/entities/*.entity.{js,ts}` before calling `runSystemSeeds()`. Diagnostic scripts under `scripts/` follow the same pattern (load `.env`, build a read-only `DataSource`, query entity counts).
