Three sibling feature packages under `src/features/`, each following a consistent `index.ts` barrel + `types/` + `hooks/` + `components/` layout:

- `utilisateurs/` — RBAC surface. Types in `utilisateur.types.ts` define `Utilisateur` (auth identity with flattened `nom/prenom/telephone` plus nested `profil` and `membrePersonnel`), `Role`, `Permission`, and their DTOs/filters. Two hook files split concerns: `use-utilisateurs.ts` wraps `/api/utilisateurs/*` CRUD plus multi-établissement assignment/toggle/suspension/password-reset/session-revoke/photo-upload/QR-code endpoints; `use-roles-permissions.ts` wraps `/api/rbac/*` for role CRUD, permission listing/grouping, direct user permissions, batch updates, and per-role detail/stats. Components are tabbed (`tab-informations`, `tab-roles-permissions`, `tab-securite`, `tab-activite`) around `utilisateur-detail-page`, plus standalone `utilisateurs-page` and `roles-page`. Query keys are centralized (`UTILISATEURS_KEYS`, `ROLES_KEYS`) as nested arrays consumed by `@tanstack/react-query`.
- `securite/` — thin feature exposing `Incident`/`Ronde` types and a single `SecuritePage` component backed by `use-securite.ts` hitting `/api/securite/*` (incidents, rondes, stats).
- `configuration/` — system settings surface. Types cover `ParametreSysteme`, module registry/config, history, and backups. `ConfigurationPage` composes four tabs (`LangueRegionTab`, `ModulesTab`, `NotificationsTab`, `SecuriteTab`) plus `HistoriqueTab` and `SecuriteActionCard`. `use-configuration.ts` manages params/modules/history/backups via `/api/configuration/*`; `useSecuriteConfig.ts` is a self-contained stateful hook that maps flat key-value `ParametreSysteme` rows into a typed `SecuriteConfigValues` model (with bidirectional `PARAM_MAPPING`/`REVERSE_MAPPING`), tracks dirty fields, validates ranges/IPs locally, and supports both auto-save toggles and batch save.

Dependency direction: components → hooks → `apiClient` (`@/lib/api-client` or `@/lib/api`) → backend REST. Hooks depend on `@/stores/auth.store` for `isAuthenticated` gating and on `sonner` for toast feedback. There is no cross-feature import between the three packages — they are independent feature slices.
