Three sibling feature packages (`eleves`, `responsables-eleves`, `diplomes-eleves`) follow an identical internal layout: `types/` holds backend-aligned interfaces plus DTOs, `hooks/` wraps TanStack Query calls via `@/lib/api-client` with centralized query keys, `components/` exposes one list page, one detail page, and one form modal, and `index.ts` acts as a barrel re-exporting types + hooks + public components. Cross-feature data is shared through other features' hooks (e.g. `useToutesClasses`, `useToutesAnneesScolaires` from `features/classes` and `features/annees-scolaires`). The `eleves` package additionally owns its own validation layer in `utils/eleve.schema.ts` using Zod split into four step schemas (`etape1IdentiteSchema` … `etape4ComplementSchema`) merged into `creerEleveCompletSchema`, driving a multi-step form; it also ships two parallel form implementations (`eleve-form.tsx` and `eleve-form.v2.tsx`) alongside a dedicated `use-eleve-documents.ts` / `use-eleve-responsables.ts` / `use-eleve-suivi.ts` hook set that compose the detail page's sub-panels. Dependency direction is strictly inward: components → hooks → apiClient; no cross-imports between the three feature packages.
