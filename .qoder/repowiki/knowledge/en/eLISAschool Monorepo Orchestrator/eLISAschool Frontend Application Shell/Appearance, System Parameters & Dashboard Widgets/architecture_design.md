Each subdirectory is an independent React feature with its own entry point (`ApparencePage.tsx`, `ParametresPage.tsx`, `DashboardPage.tsx`) re-exported via an `index.ts`. Data access is centralized in per-feature hooks built on `@tanstack/react-query` and `apiClient`:
- `apparence/`: `hooks.ts` exposes queries/mutations for catalogue, establishment fonds, and rotation config; `types.ts` defines `Fond`, `CategorieFond`, and `CATEGORIE_LABELS`; `ApparencePage.tsx` orchestrates catalog browsing, batch selection, active-fond application (with special handling for virtual `systeme-*` fonds that create real associations), and preview.
- `parametres/`: `hooks/use-parametres.ts` groups all CRUD + bulk/reset mutations under a shared `PARAMETRES_KEYS` cache namespace, with `enabled: isAuthenticated` guards; `types/parametres.types.ts` holds DTOs (`CreateParametreDto`, `UpdateParametreDto`, `ParametreFiltres`).
- `dashboard/`: single-page component that calls `/api/dashboard/widgets`, falls back to a hardcoded default widget list when the API is unavailable, and maps string icon names to Lucide components via an `ICON_MAP`.
Dependency direction is one-way: pages → feature hooks → `apiClient` → backend REST endpoints. No cross-feature imports exist between these three modules.
