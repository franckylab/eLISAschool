Three sibling feature packages (`matieres`, `cycles`, `niveaux`) follow an identical internal layout: a `types/` directory holding the domain DTOs/interfaces, a `hooks/` directory wrapping each entity in `@tanstack/react-query` hooks (list/detail + create/update/delete mutations), and a `components/` directory exposing a list page plus a detail/form modal. Each package re-exports its public surface from a single barrel `index.ts`. The `matieres` package is the most complex: it owns not only the `Matiere` CRUD but also the `MatiereNiveau` programme-linking layer, the `AffectationMatiere` teacher-class assignment layer, and the `ConfigurationMatiereClasse` per-class configuration layer, plus a `useConfigurationEffective` hook that merges defaults with overrides via `/api/matieres/:id/configurations/effective`. It additionally re-exports `ProgrammePedagogique`/`ProgrammeMatiere` from `features/programmes/types/programme.types.ts` to keep programme types centralized. Dependency direction inside this module is one-way: components → hooks → `apiClient` → backend REST endpoints; there are no cross-imports between the three feature packages, so they remain independent despite sharing the same academic domain.
