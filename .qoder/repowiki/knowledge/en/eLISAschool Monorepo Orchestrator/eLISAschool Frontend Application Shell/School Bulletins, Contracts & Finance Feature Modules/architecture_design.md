Three sibling feature packages under `src/features/`, each following the same internal layout: `index.ts` barrel re-exports types from `types/*.ts`, hook functions from `hooks/use-*.ts`, and one or more page components from `components/`. Data access is centralized in the hooks layer built on `@tanstack/react-query` (`useQuery`/`useMutation`) with a shared `apiClient` (`@/lib/api-client`) and authentication gating via `useAuthStore`; mutations call `queryClient.invalidateQueries` keyed by a module-scoped `*_KEYS` object to keep lists consistent. UI state is kept local inside the page components; there are no Redux/Zustand stores in this scope. The three features target distinct REST surfaces — `/api/bulletins/*`, `/api/personnel/contrats*` and `/api/personnel/types-contrat*`, `/api/finances/*` — and expose DTOs (`GenererBulletinDto`, `CreerFraisDto`, `CreerPaiementDto`) alongside entity interfaces, keeping request/response shapes separate from persisted models.
