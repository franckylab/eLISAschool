Each sub-folder (`notes/`, `examens/`, `examens-nationaux/`) is a self-contained React feature following an identical layout: `types/*.types.ts` (domain DTOs + filter shapes), `hooks/use-*.ts` (React Query data layer wrapping REST endpoints via `apiClient` from `@/lib/api-client` or `@/lib/api`), `components/*-page.tsx` (route pages; `examens-nationaux` additionally exposes a reusable `ExamenNationalFormModal`), and a barrel `index.ts` re-exporting types, hooks, and page components.

Dependency direction is strictly one-way: components → hooks → `apiClient` → backend `/api/...`; hooks depend only on `@tanstack/react-query`, `@/stores/auth.store` (for `isAuthenticated` guards), and `sonner` for toast feedback. There is no shared business logic between the three features — they are parallel implementations of the same pattern against different resource families (`/api/notes`, `/api/examens`, `/api/examens-nationaux`).

The `examens-nationaux` module is the most recent addition (versioned header, explicit author comment) and uses the generic `PaginatedResult<T>` shape from `@shared/types/api.types`, whereas `notes` and `examens` still inline their own pagination/response unwrapping, reflecting ongoing migration toward the shared contract.
