Three sibling feature packages (`paie/`, `conges/`, `pointages/`) share an identical internal layout: a `components/` folder with one page-level React component per feature, a `hooks/` folder exporting TanStack Query hooks (`useQuery`/`useMutation`) that call the backend via `apiClient`, a `types/` folder with TypeScript interfaces mirroring server DTOs, and a thin `index.ts` barrel re-exporting the public API. The `paie` feature is the most complex, adding modal components (`bulletin-form-modal`, `cotisation-modal`, `prime-modal`, `retenue-modal`) and a permission hook (`use-paie-permissions`). Each hook module defines a local `*_KEYS` constant for query key factories, uses `@tanstack/react-query` for caching, `sonner` for toast notifications, and `useAuthStore` to gate queries on `isAuthenticated`. All HTTP calls go through a shared `apiClient` from `@/lib/api` or `@/lib/api-client`, keeping the features decoupled from transport details. Dependency direction is strictly one-way: components → hooks → apiClient; types are consumed by both layers but never imported back into hooks.
