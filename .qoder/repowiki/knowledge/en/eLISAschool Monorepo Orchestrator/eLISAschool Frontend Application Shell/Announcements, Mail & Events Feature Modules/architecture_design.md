Each sub-feature follows an identical three-layer layout: `types/<entity>.types.ts` declares the domain DTOs/interfaces; `hooks/use-<entity>.ts` wraps them in TanStack Query hooks (`useQuery`/`useMutation`) that call `apiClient.getPaginated`, `post`, `patch`, `delete` against `/api/<entities>` and invalidate a typed `*_KEYS` query-key tree on success; `components/<entity>-page.tsx` is a stateless page consuming those hooks and rendering a shared `DataTable` with inline column definitions. A thin `index.ts` barrel re-exports types, hooks, and the page component. Features are independent — no cross-imports between annonces/courriers/evenements — and depend only on shared UI primitives (`@/components/ui/*`), auth store (`@/stores/auth.store`), and i18n via `react-i18next` namespaces matching the feature name.
