Three sibling feature packages under `src/features/`, each following a consistent React + TanStack Query layout: `types/` (domain DTOs), `hooks/` (data access via `apiClient` from `@/lib/api-client`), `components/` (pages + modals), and an `index.ts` barrel re-exporting public APIs.

- `annees-scolaires/`: thin wrapper around `/api/annees-scolaires`; includes a local `AnneeScolaireBackend` interface plus `mapperAnneeScolaire` that translates backend `enCours`/`OUVERTE|EN_COURS|EN_ATTENTE_CLOTURE|CLOTUREE` into frontend `estActuelle`/`active|inactive|future|archivee`. The list endpoint returns a plain array, so hooks wrap it in a `PaginatedResult` for the shared DataTable.
- `periodes/`: the largest feature, implementing v5.0 where the old `TypePeriode` enum is replaced by the configurable `NiveauPeriode` entity linked via `periode.niveauId`. It owns CRUD for periods, compositions (parent-child tree), templates (`TemplatePeriodeEntity` with recursive `NoeudTemplatePeriode`), closure/reopening workflows, plus full CRUD for `NiveauPeriode` and `UsageNiveau` entities. Hooks are grouped by resource (`PERIODES_KEYS.templates`, `.niveaux`, `.usages`).
- `structure-academique/`: lightweight utility feature exposing `use-structure-academique-utils` and a single page; acts as a helper layer consumed by other features.

Cross-feature coupling: `annees-scolaires/types` imports `NiveauPeriode` from `periodes/types`, establishing a one-way dependency `annees-scolaires → periodes`. Both features depend on `@/stores/auth.store` for `etablissementId`/`isAuthenticated` gating and on `sonner` for toast feedback. No component imports another feature's components — only types flow across boundaries.
