The root is an npm workspaces monorepo (`package.json` declares `backend`, `frontend`, `shared`) whose only orchestration role is to expose unified commands that delegate to children: `dev` launches both servers concurrently, `build`/`test`/`lint` propagate via `--workspaces`, and `db:migrate`/`db:seed` proxy to the backend workspace. The single source of truth across services is the `shared_library` package — both backend (Nest/Express+TypeORM) and frontend (React+Vite) import the same enums, Zod validators and configuration registry so API contracts and UI types stay in sync. Cross-cutting concerns are kept out of child code: per-module deployment and maintenance live under `scripts/` (multi-tenant deploy, config refonte, scoring diagnostics), while environment provisioning is delegated to `docker_infra`'s `docker-compose.dev.yml` / `docker-compose.yml`. Release state is tracked at the root via `VERSION`, `ETAPES-*` files and `INDEX.md`, which all children reference rather than maintaining their own changelogs.
