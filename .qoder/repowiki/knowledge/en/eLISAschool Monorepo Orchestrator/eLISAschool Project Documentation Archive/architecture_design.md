Flat Markdown repository with no build tooling; a single `INDEX.md` acts as the navigation hub linking to ~400 documents grouped into 15 thematic folders (`analyses/`, `corrections/`, `implementations/`, `guides/`, `rapports/`, `syntheses/`, `resumes/`, `audits/`, `certifications/`, `checklists/`, `configurations/`, `deploiements/`, `migrations/`, `ameliorations/`, `autres/`). Root-level files provide cross-cutting references: `technical.md` (system architecture overview), `rbac-system.md` / `CONVENTIONS-PERMISSIONS.md` / `EXEMPLE-INTEGRATION-PERMISSIONS.md` (RBAC reference), `user-guide.fr.md` (end-user guide), plus two TypeScript example snippets (`guards-exemples-implémentation.ts`, `guide-implémentation-permissions.ts`) that mirror backend guard patterns. The `stats.json` file is consumed by the index to render document counts. There are no runtime dependencies — this module is purely an informational artifact consumed by developers, testers and project managers.
