Flat Markdown repository with no build tooling — a human-maintained knowledge base split into ~15 thematic top-level directories (analyses, corrections, ameliorations, implementations, guides, audits, certifications, checklists, configurations, deploiements, migrations, rapports, syntheses, resumes, autres) plus root-level reference documents (INDEX.md, technical.md, rbac-system.md, user-guide.fr.md). The `autres/` sub-tree groups ephemeral or cross-cutting artifacts under `_`-prefixed folders (`_backup-system`, `_divers`, `_fix`, `_formulaire`, `_frontend`, `_gamification`, `_improvements`, `_integration`, `_multi-tenant`, `_notifications`, `_optimisations`, `_phase1`, `_quick-start`, `_rbac`, `_refactorisation`, `_seeds`, `_sessions`, `_summary`) to separate transient work-in-progress from stable deliverables. `stats.json` is an external index maintained alongside INDEX.md for machine-readable category counts and recent-document lists; there are no scripts that regenerate it inside this scope. Cross-links between categories are purely relative Markdown links — dependency direction is one-way: each document references peers but nothing in code consumes these files at runtime.
