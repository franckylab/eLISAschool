- Document filenames use a fixed prefix indicating category and purpose (e.g. `ANALYSE-*`, `CORRECTION-*`, `IMPLEMENTATION-*`, `GUIDE-*`, `RAPPORT-*`, `SYNTHESE-*`, `RESUME-*`, `AUDIT-*`, `CONFIGURATION-*`, `DEPLOYMENT-*`, `MIGRATION-*`, `AMELIORATION-*`) followed by a descriptive slug in uppercase or PascalCase.
- Obsolete or superseded documents are kept for history but marked with a leading `⚠️ DOCUMENT OBSOLÈTE` banner inside the file rather than deleted, so the index can still link to them while warning readers.
- Each folder groups documents by development lifecycle stage (analysis → implementation → correction → report → summary) and the root `INDEX.md` mirrors this structure with a table per category listing every file, its one-line description and a status emoji.
