Three thin TanStack Router `createFileRoute` declarations (`/login`, `/forgot-password`, `/reset-password`) that act as a routing facade: they import stateful page components from `@/features/auth/*` and enforce access via `publicOnlyGuard()` in `beforeLoad`. Search params are declared with `validateSearch` — `redirect` on login and `token` on reset — so downstream features receive typed query values. The module has no business logic; it only wires routes to feature components and applies the shared guard from `@/app/route-guards`.
