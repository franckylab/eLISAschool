Two parallel language trees under `frontend/src/locales/{fr,en}/` mirror each other one-to-one: every `<domain>.json` present in `fr/` has an exact counterpart in `en/`. Each file is a plain JSON object whose top-level keys group related strings (`boutons`, `messages`, `validation`, `dates`, `navigation`, `filtres`, etc.) and whose leaf values are translatable strings; some leaves use double-brace interpolation placeholders (`{{page}}`, `{{total}}`, `{{email}}`, `{temps}`, `{nb}`) consumed by the application's i18n loader at build/runtime. There is no executable code inside this scope — it is pure data. The naming convention uses kebab-case filenames that map to feature domains (absences, eleves, notes, paie, securite-config, …) plus a shared `common.json` for cross-cutting UI text such as buttons, validation messages, dates, pagination, and the establishment-selection modal.
