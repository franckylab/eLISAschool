Thin TanStack Router file-route layer under `(authenticated)/parametres/structure-academique/`. Each `.tsx` file declares one route via `createFileRoute` and maps it to a page component re-exported from a sibling feature package (`@/features/<feature>`): `route.tsx` → `StructureAcademiquePage`, `cycles.tsx` → `CyclesPage`, `filieres.tsx` → `FilieresPage`, `niveaux.tsx` → `NiveauxPage`, `diplomes-eleves.tsx` → `DiplomesElevesPage`, `examens-nationaux.tsx` → `ExamensNationauxPage`. The routes are grouped under the authenticated layout at `/parametres/structure-academique/*`, keeping all business logic in the corresponding `@/features/*` packages so this directory contains only routing glue with no UI or state logic of its own.
