Each child domain (finances, paie, cantine, transport, parking, materiel) is a self-contained Express module following the same barrel-export pattern: an `index.ts` re-exports entities, dto, services, and controllers so the parent application mounts them via a single import. Modules are isolated — they own their own TypeORM entities, DTOs, services, and controllers, with no cross-module imports between them; shared business logic lives in the parent application layer or in the common `personnel`/`organisation` modules referenced by the coding intent. Finances and paie are the only modules that reference external personnel/organisation concepts (e.g., TypePersonnel/Fonction), while cantine/transport/parking/materiel are pure CRUD logistics modules. Each module exposes its own config file (`*.config.ts`) for domain-specific settings, and cron jobs (e.g., finances `cron-jobs.ts`) run inside the module process.
