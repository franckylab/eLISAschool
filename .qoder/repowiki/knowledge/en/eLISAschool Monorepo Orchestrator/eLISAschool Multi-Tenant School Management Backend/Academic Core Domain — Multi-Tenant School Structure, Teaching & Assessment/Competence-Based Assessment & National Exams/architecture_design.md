Two sibling Nest/Express-style modules, each following a flat four-layer layout (`entities` / `dto` / `services` / `controllers`) re-exported through an `index.ts` barrel. Both depend on shared infrastructure via path aliases: `@database/data-source` for TypeORM repositories, `@common/filters/error.filter` for `AppError`, `@common/utils/pagination.util` for `paginateWithQueryBuilder`, and `@modules/auth/middlewares` for `authMiddleware` + `requirePermission('config:edit')`. The `competences` module is multi-tenant: every query is scoped by `etablissementId` injected from `req.utilisateur.etablissementId`, enforced at both controller and service layers, and backed by a composite unique index on `(niveauId, matiereId, etablissementId)` plus per-column indexes. `EvaluationCompetence` bridges the traditional `Note` entity to the APC model via a one-to-one link, carrying a `NiveauMaitrise` enum plus derived getters (`scoreNumerique`, `pourcentage`, `niveauLabel`, `niveauColor`). The `examens-nationaux` module is non-tenant and models official certifications (CEP, BEPC, BACCALAURÉAT, GCE O/A Level) linked to `Niveau`, with a global unique `code` constraint. Dependency direction inside each module is strictly controllers → services → entities; DTOs are pure validation schemas consumed by controllers.
