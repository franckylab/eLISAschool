Each sub-module follows the same layered structure: `index.ts` re-exports entities/dto/services/controllers and wires an Express Router; controllers define REST endpoints with Zod-based validation via a local `validate()` helper; services encapsulate business logic using TypeORM repositories obtained from `AppDataSource`; entities are decorated with TypeORM decorators (`@Entity`, `@Column`, `@ManyToOne`, etc.). The `apparence` module models a global `Fond` catalog linked to per-establishment selections via `FondEtablissement`, with system defaults falling back when none are selected. The `options` module models `InscriptionOption` linking Eleve→Matiere→AnneeScolaire with a three-state status workflow (EN_ATTENTE → ACTIVE/ABANDONNEE). Both modules depend on shared infrastructure (`@common/filters/error.filter`, `@common/utils/logger.util`, `@modules/auth/middlewares`) but have no cross-dependencies between them.
