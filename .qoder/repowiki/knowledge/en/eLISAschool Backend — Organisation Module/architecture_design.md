The module follows a strict layered architecture within `backend/src/modules/organisation/`: entities define TypeORM models (`unite-organisationnelle.entity.ts`, `poste.entity.ts`, `hierarchie-personnel.entity.ts`, etc.) with multi-tenant `etablissementId` scoping; DTOs use Zod schemas for request validation; services encapsulate business logic (CRUD, tree building, PDF generation, statistics, Redis caching); controllers are thin Express routers that validate input via `validateDto`, enforce permissions through `authMiddleware` + `requirePermission('organisation:*')`, and delegate to services. The barrel `index.ts` files re-export everything for clean imports from `@modules/organisation`. Controllers are mounted under `/api/organisation` in `app.ts` with `filterByEtablissement()` ensuring tenant isolation. Redis is used as an optional distributed cache with automatic fallback to in-memory when unavailable. The module integrates with personnel, etablissement, and audit subsystems through shared types and repositories.
