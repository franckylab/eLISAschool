Module routes are registered in `backend/src/app.ts` under `/api/organisation` with `authMiddleware` and `filterByEtablissement()`. Database migrations live in `backend/database/migrations/` (SQL files like `109-refonte-organisation.sql`, `110-consolidation-organisation.sql`). Development uses `npm run dev` via nodemon, migrations run with `typeorm migration:run -d src/database/data-source.ts`, and seeds via `ts-node src/database/seeds/run-seeds.ts`.
