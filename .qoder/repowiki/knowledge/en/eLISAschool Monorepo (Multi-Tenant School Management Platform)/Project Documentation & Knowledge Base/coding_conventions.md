- Document filenames use a fixed uppercase prefix followed by a descriptive slug (e.g. `ANALYSE-*`, `CORRECTION-*`, `IMPLEMENTATION-*`, `RAPPORT-*`, `GUIDE-*`, `SYNTHESE-*`, `RESUME-*`, `AMELIORATION-*`, `MIGRATION-*`, `DEPLOYMENT-*`, `AUDIT-*`, `CHECKLIST-*`, `CONFIGURATION-*`, `MAJ-*`) so they sort chronologically within their category.
- Cross-references inside documents link to sibling files using relative Markdown paths from `docs/` (e.g. `[ANALYSE-ARCHITECTURE-MULTI-TENANT.md](analyses/ANALYSE-ARCHITECTURE-MULTI-TENANT.md)`), never absolute URLs, keeping the index as the single source of truth.
- Obsolete or superseded documents are retained in place but prefixed with a `⚠️ DOCUMENT OBSOLÈTE` marker in their title and referenced from `INDEX.md` with an explicit 'Obsolète' status column instead of being deleted.
