Pure Markdown repository with no build step; a flat `INDEX.md` at the root acts as the central navigation hub linking into 15 top-level subdirectories (`analyses/`, `corrections/`, `implementations/`, `guides/`, `rapports/`, `syntheses/`, `resumes/`, `audits/`, `certifications/`, `checklists/`, `configurations/`, `deploiements/`, `migrations/`, `ameliorations/`, `autres/`). The `autres/` subtree is further subdivided by topic prefix (`_backup-system/`, `_divers/`, `_fix/`, `_formulaire/`, `_frontend/`, `_gamification/`, `_improvements/`, `_integration/`, `_multi-tenant/`, `_notifications/`, `_optimisations/`, `_phase1/`, `_quick-start/`, `_rbac/`, `_refactorisation/`, `_seeds/`, `_sessions/`, `_summary/`) to group ephemeral or cross-cutting artifacts. Root-level reference documents (`technical.md`, `rbac-system.md`, `user-guide.fr.md`, `CONVENTIONS-PERMISSIONS.md`, `PERMISSIONS-BASE-DONNEES.md`, `guards-exemples-implémentation.ts`, `guide-implémentation-permissions.ts`) provide system-wide entry points consumed by the index. There are no code dependencies between files — the structure is purely navigational, organized around the project's development lifecycle (analysis → implementation → correction → report → summary) rather than runtime concerns.
