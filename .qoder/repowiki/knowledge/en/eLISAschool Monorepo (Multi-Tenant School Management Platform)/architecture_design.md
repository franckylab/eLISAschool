The workspace root is an npm workspaces monorepo (`package.json` `workspaces: [backend, frontend, shared]`) that publishes no code itself — it only declares cross-module wiring. The three sibling packages share one contract surface via the `shared` package (enums, Zod validators, theme/app constants, module config registry), which both `backend` and `frontend` import so their type surfaces stay in sync. Top-level `npm run dev`, `build`, `test`, `lint`, and `db:migrate`/`seed` scripts delegate to each child's own scripts through `--workspace=...`, while Docker compose files under `docker_infra` (referenced by `docker:dev` / `docker:prod`) bring up PostgreSQL, Redis, pgAdmin, the backend container, and the frontend container together. A `postinstall` override pins `@types/express` against a transitive conflict, and `engines` enforces Node ≥20 / npm ≥10 across all children. The `scripts_tooling` directory provides deployment and seed helpers invoked from the README (e.g. `deploy-structure-academique.sh`).
