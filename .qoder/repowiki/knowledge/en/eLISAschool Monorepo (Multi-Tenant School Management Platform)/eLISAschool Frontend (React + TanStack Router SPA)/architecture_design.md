The app is a Vite-built React 19 SPA using TanStack Router's file-based route tree (`src/routes/`) generated at build time via `@tanstack/router-cli` into `routeTree.gen.ts`. The entrypoint `main.tsx` mounts `<Providers>` (wrapping `QueryClientProvider` from `@tanstack/react-query` and a Sonner toaster) around `App`, which creates the router instance and renders `RouterProvider` plus a dev-only debug panel. State is split across two layers: global UI state in Zustand stores under `src/stores/` (auth, theme, language, sidebar) and server state managed by TanStack Query with a shared `query-client.ts` config (5 min staleTime, exponential retry). Business logic is organized as feature modules under `src/features/<domain>/` each following a consistent layout of `components/`, `hooks/`, `types/`, and an `index.ts` barrel; domain pages are wired to routes via `_auth.*.tsx` files that share authenticated layout guards defined in `src/app/route-guards.ts` and `permission-guards.ts`. Shared primitives live in `src/components/ui/` (Radix-based primitives like `ElisaButton`, `ElisaInput`, `DataTable`, etc.) and cross-cutting concerns in `src/hooks/` (auth, permissions, pagination, breakpoints, i18n, multi-tenant selection). Internationalization uses `i18next` + `react-i18next` with per-feature JSON bundles under `locales/{fr,en}/`. Static assets (favicons, login backgrounds, icons) sit in `public/`, and a small CLI script under `scripts/` generates favicons via Sharp.
