Prerequisites: Docker, Docker Compose, and OpenSSL must be installed. Run `./deploy.sh <mode> [action]` where mode is one of `local-dev`, `local-prod`, `cloud-dev`, `cloud-prod` and action is `up|down|restart|rebuild|status|logs`. Secrets are auto-generated on first run if `.env.*` files contain `__AUTO_GENERATE__` markers. For local development, the script auto-configures CORS based on detected host IP. Cloud modes support automatic Let's Encrypt SSL in production.
