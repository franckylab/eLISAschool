All scripts must be made executable once (`chmod +x scripts/*.sh`). The canonical bootstrap is `./scripts/start-dev.sh [--backend|--frontend|--all]`; full one-shot install is `./scripts/deploy-complet.sh` which creates the DB, runs every `*.sql` in `backend/database/migrations/`, then executes `src/database/seeds/run-seeds.ts`. Permission audits are run via `node scripts/check-permissions.js` and super-admin fixes via `./scripts/fix-super-admin-permissions.sh` (interactive prompts for host/port/user/password/email).
