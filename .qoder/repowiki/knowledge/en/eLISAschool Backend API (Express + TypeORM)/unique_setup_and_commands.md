Development server: `npm run dev` (nodemon + ts-node with `tsconfig-paths/register`). Production build: `npm run build` then `npm start` (falls back to ts-node if dist missing). Database migrations: `npm run migration:run` / `migration:generate` / `migration:revert` against `src/database/data-source.ts`. Seeds: `npm run seed` (all), `seed:rbac`, `seed:demo`. Tests: `npm test` / `test:watch` / `test:coverage`. Index diagnostics: `npm run db:analyze-indexes` and `npm run db:fix-duplicate-index`.
