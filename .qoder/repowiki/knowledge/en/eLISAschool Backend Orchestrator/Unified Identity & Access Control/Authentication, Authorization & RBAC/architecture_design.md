- **Layered structure**: Controllers (Express routers) → Services (business logic) → Entities (TypeORM models), with DTOs for validation schemas and Guards/Middlewares for request interception.
- **Entry point**: `index.ts` re-exports all sub-modules (entities, dto, services, controllers, middlewares, guards) as a unified module facade.
- **Core services**: `AuthService` handles login/register/password flows; `TokenService` manages JWT access tokens and database-backed refresh tokens; `PermissionResolverService` resolves effective permissions from multi-role assignments with recursive inheritance and in-memory caching (5-min TTL); `AuditService` logs security-sensitive actions.
- **Authorization boundary**: Two parallel mechanisms — role-based middleware (`role.middleware.ts`) checks user roles against allowed lists; permission-based guard (`permission.guard.ts`) verifies granular permissions embedded in JWT payloads with fallback to static role-permission mappings.
- **Dependency direction**: Controllers depend on services; services depend on TypeORM repositories and shared utilities (`@common`, `@shared`, `@config`); entities define relations to external modules (e.g., `Etablissement`).
- **Multi-tenancy**: `UtilisateurEtablissement` entity enables users to belong to multiple establishments; `switch-etablissement` endpoint regenerates JWT with updated `etablissementId` context.
