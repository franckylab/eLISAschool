- **Configuration Module**: Implements a hybrid storage strategy using `ConfigurationApp`, `ConfigurationModule`, and `ParametreSysteme` entities with a multi-tenant fallback mechanism (establishment-specific overrides falling back to global defaults). It features an in-memory caching layer (`ConfigCache`) with TTL-based invalidation and an event-driven architecture via `ConfigurationListener` (EventEmitter) to broadcast changes.
- **TypeEnum Module**: Provides dynamic management of system enums (e.g., document types, statuses) with strict protection for system-seeded records (`estSysteme` flag) while allowing custom extensions per establishment.
- **Groupes Module**: Facilitates the logical grouping of establishments for cross-entity dashboards. It uses `ConsolidationService` to aggregate statistics (students, grades, finances) across multiple tenants, employing raw SQL queries for performance and a dedicated cache layer for dashboard data.
- **Security**: All modules enforce RBAC via custom guards (`config.guard.ts`, `groupe-access.guard.ts`) and role-based middleware, ensuring strict isolation of administrative actions.
