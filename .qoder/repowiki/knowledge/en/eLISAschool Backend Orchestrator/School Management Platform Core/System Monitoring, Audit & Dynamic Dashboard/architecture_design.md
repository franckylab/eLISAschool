- **Audit Sub-module**: Exposes REST endpoints for querying and exporting audit logs, restricted to admin roles, and delegates persistence to the auth module's audit service (`audit.controller.ts`, `archivage.service.ts`).
- **Monitoring Sub-module**: Implements system health checks, resource metrics (CPU/Memory), and maintenance mode toggling via `MonitoringService`, using Node.js `os` and TypeORM status checks (`monitoring.service.ts`).
- **Dashboard Sub-module**: Features a declarative widget registry (`widget-registry.ts`) that maps widgets to data resolvers. It uses a `DataAggregatorService` for lazy-loading cross-module services, a `WidgetResolverService` for RBAC-based visibility, and a `DashboardCacheService` with Redis/in-memory fallback for performance (`dashboard-data.service.ts`, `dashboard-sse.service.ts`).
- **Real-time Updates**: Supports Server-Sent Events (SSE) for live dashboard updates via `DashboardSSEService`, managing client connections and heartbeats.
