- Three sub-modules (`auth`, `utilisateurs`, `configuration`) each follow a controller-service-entity/DTO layering pattern, exported via barrel `index.ts` files (e.g. `backend/src/modules/auth/index.ts`).
- The `auth` module owns the full auth flow: `auth.controller.ts` defines Express routes for login/register/refresh/logout/password-reset/email-verify; `auth.service.ts` orchestrates credential validation, account lockout, token generation, and audit logging; `token.service.ts` manages JWT signing/verification (jsonwebtoken) and database-backed refresh-token lifecycle; `auth.middleware.ts` extracts and validates Bearer tokens, attaching `UtilisateurAuth` to `req.utilisateur`; `role.middleware.ts` and `permission.guard.ts` enforce role-based and permission-based access control.
- The `utilisateurs` module provides CRUD operations on users and profiles via `utilisateurs.controller.ts` and `utilisateurs.service.ts`, reusing `Utilisateur` and `ProfilUtilisateur` entities from the `auth` module and applying `requireRoles` / `adminOnly` guards for admin-only mutations.
- The `configuration` module implements a hybrid configuration store: `configuration.service.ts` manages application-level config, per-module settings, and system parameters with an in-memory cache (5-minute TTL), automatic invalidation on writes, and event emission via `configuration-listener.ts`; `config.helper.ts` exposes typed helpers (`getParam`, `getParamNumber`, `getParamBoolean`) consumed by other modules (e.g. `auth.service.ts` reads `auth.max_login_attempts`); `configuration.controller.ts` exposes REST endpoints guarded by fine-grained permission checks from `guards/config-permissions.ts` and `guards/config.guard.ts`; `configuration-history.service.ts` records change history and supports backup/restore.
- Shared entities (`utilisateur.entity.ts`, `profil-utilisateur.entity.ts`, `refresh-token.entity.ts`, `audit-log.entity.ts`) use TypeORM decorators with bcrypt password hashing; DTOs use Zod schemas for request validation across all three sub-modules.
