Build/dev driven by Vite (see workspace root `frontend/package.json`); runtime API base URL is controlled by the `VITE_API_URL` env var — when empty the Vite dev proxy forwards `/api` requests to the backend, otherwise it points at a production server. Locale bundles are statically imported in `src/lib/i18n.ts`, so adding a new language requires updating both the imports and the `ns` array there.
