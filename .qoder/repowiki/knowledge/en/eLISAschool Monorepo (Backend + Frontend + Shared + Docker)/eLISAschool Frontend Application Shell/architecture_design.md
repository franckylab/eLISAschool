Single-page React application bootstrapped from `src/main.tsx`, which mounts a `<Providers>` wrapper (TanStack Query client + Sonner toasts) around the root `<App>` component. Routing is file-based via TanStack Router: routes live under `src/routes/` with `_auth.*` prefix files forming an authenticated layout tree, while `__root.tsx` wraps everything in an `ErrorBoundary`. The app shell (`src/app/App.tsx`) creates the router instance, applies theme and auth initialization, and injects a dev-only debug panel.

Cross-cutting concerns are split into dedicated layers:
- `src/lib/` — framework-agnostic utilities: `api-client.ts` (singleton HTTP client with JWT Bearer, automatic refresh, request/response interceptors, and multi-tenant `etablissementId` validation), `query-client.ts` (TanStack Query defaults), `i18n.ts` (i18next with statically imported `fr`/`en` JSON namespaces per feature), plus helpers (`cn`, date/format/theme utils).
- `src/stores/` — Zustand stores (`auth.store.ts` persisted to localStorage via `zustand/middleware/persist`, plus theme/language/sidebar stores) exposing typed selectors/actions consumed by components and hooks.
- `src/hooks/` — composable React hooks (`use-auth`, `use-permissions`, `use-pagination`, `use-datatable-preferences`, etc.) that wrap stores and API calls.
- `src/components/` — reusable UI organized by concern (`ui/` primitive components, `layout/`, `feedback/`, `permissions/`, `navigation/`, `branding/`, `charts/`, `modals/`, `auth/`).
- `src/features/<domain>/` — feature folders following a consistent `components/`, `hooks/`, `types/`, `index.ts` layout; each feature owns its own domain logic and is wired into the route tree.

Dependency direction is strictly inward: features → hooks → stores/lib → components; routes compose features and layout but never import sibling features directly. Multi-tenancy flows through the auth store's `etablissementId` field and the API client's token payload validation, with a pre-login / complete-login two-step flow gated by `EtablissementSelectionModal`.
