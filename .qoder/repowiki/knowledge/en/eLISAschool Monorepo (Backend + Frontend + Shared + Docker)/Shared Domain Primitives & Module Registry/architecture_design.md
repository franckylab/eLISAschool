Published as the private npm package `@elisaschool/shared` (`dist/index.js`, `dist/index.d.ts`) built with plain `tsc`. The barrel `src/index.ts` re-exports six flat sub-packages — `enums/`, `constants/`, `types/`, `validators/`, `config/`, plus one helper — so consumers import from a single entry point. Runtime behaviour is split into two layers: (1) pure data contracts (Zod schemas in `validators/auth.validators.ts`, TypeScript interfaces in `types/`, enum sets in `enums/`, literal constants in `constants/`) that have no side effects and are safe to ship to the browser; (2) application-level configuration in `config/config.registry.ts`, which defines a `ModuleConfig` interface and a large `MODULE_REGISTRY` mapping every `ModuleName` to its label, base path, default roles, permissions, dependencies, and per-module `defaultSettings`, together with query helpers `getModuleConfig`, `getModulesByCategory`, and `hasModuleAccess`. A small runtime guard helper lives in `helpers/system-protection.helper.ts` (`assertNotSystem`, `assertNotImmutable`) for protecting seed entities. Dependency direction is strictly inward: `config` depends on `enums`, `validators` depend on `constants`, and nothing imports back from `config` or `helpers` into the contract layer.
