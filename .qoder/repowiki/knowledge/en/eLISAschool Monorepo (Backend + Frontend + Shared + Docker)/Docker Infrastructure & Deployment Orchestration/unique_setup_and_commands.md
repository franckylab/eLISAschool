Prerequisites: Docker + `docker compose` plugin + OpenSSL installed. First run requires copying an env template and running `./deploy.sh <mode> up`; the script auto-generates secrets if placeholders are present and validates minimum lengths in prod modes. Cloud modes require setting `DOMAIN_NAME` in `docker/.env.cloud` before `cloud-prod` enables automatic HTTPS. Port layout: backend 7000, frontend 7001, postgres 7002, redis 7003, pgAdmin 7004.
