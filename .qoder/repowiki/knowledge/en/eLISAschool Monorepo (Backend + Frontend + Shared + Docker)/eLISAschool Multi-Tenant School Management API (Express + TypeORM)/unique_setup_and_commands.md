Entry point expects a `.env` file resolved from `process.cwd()/../../.env`, `process.cwd()/.env`, or `__dirname/../../.env`; `ENABLE_CRON_JOBS=true` or `NODE_ENV=production` is required to start background jobs. Database schema is driven by two migration sources — raw SQL files in `backend/database/migrations/` and TS files in `src/database/migrations/` — selected at runtime by `databaseConfig.migrations` based on `isProduction`. Seed data is bootstrapped via `src/database/seeds/run-seeds.ts` / `run-demo-seeds.ts` / `run-rbac-seed.ts`, and one-off fixes via `src/database/scripts/*.ts` and `backend/scripts/*.ts`.
