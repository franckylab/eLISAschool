Layered Express module under `@modules/responsables-eleves` with a flat sub-package layout:
- `entities/responsable-eleve.entity.ts` — TypeORM `ResponsableEleve` join table linking two `Utilisateur` rows (parent + child) plus granular boolean flags (`responsableLegal`, `peutConsulter`, `peutPayer`) and contact fields; unique index on `(enfantId, utilisateurId)`.
- `dto/responsables-eleves.dto.ts` — Zod schemas (`lierParentSchema`, `updateResponsableSchema`, …) consumed by the controller's local `validateDto` helper.
- `services/parents.service.ts` — Core CRUD over `ResponsableEleve` via `AppDataSource.getRepository(...)`, including fallback logic in `getParentsInfo` that merges pre-enrollment direct fields from `Eleve` when no linked account exists, and a migration helper `migrerDepuisChampsDirects` to promote pre-enrollment parents into accounts.
- `services/portal-parent.service.ts` — Read-only aggregator that enforces access via `parentsService.peutAccederEleve` / `peutPayerPourEleve` before delegating to sibling modules (`notesService`, `bulletinsService`) and raw repositories (`InscriptionCantine`, `InscriptionTransport`, `RecuPaiement`).
- `controllers/responsables-eleves.controller.ts` — Single Express `Router` exposing three route families: admin CRUD (`/lier`, `/eleve/:enfantId/parents`, `/parent/:parentId/enfants`, `/:parentId/:enfantId`), parent self-service (`/mes-enfants`, `/verifier-acces/:eleveId`), and a `/portal/*` namespace for the parent dashboard. Every route is guarded by `authMiddleware` + `requirePermission('eleves:manage'|'responsables:view'|...)` from `@modules/auth/middlewares`.
- `middlewares/parent-access.guard.ts` — Reusable `requireParentAccess` / `requireParentPaymentAccess` factory middlewares extending `Express.Request` with `parentAccessVerified` / `parentPaymentVerified` / `eleveUtilisateurId` for cross-module authorization.
- `index.ts` re-exports all sub-packages as a single barrel.

Dependency direction: controller → services → TypeORM repos + sibling modules (`@modules/auth`, `@modules/notes`, `@modules/bulletins`, `@modules/eleves`, `@database/data-source`, `@common/filters/error.filter`, `@common/utils/logger.util`). The module depends outward on auth permissions and other domain modules but exposes no internal coupling between its own sub-packages beyond the service layer.
