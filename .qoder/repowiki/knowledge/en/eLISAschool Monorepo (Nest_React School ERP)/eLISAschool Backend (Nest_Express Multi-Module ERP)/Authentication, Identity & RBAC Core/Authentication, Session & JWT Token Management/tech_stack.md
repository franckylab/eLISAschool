Express Router for HTTP; `jsonwebtoken` for signed access tokens (issuer `eLisaschool`, audience `elisaschool-api`, secret from `envConfig.jwt.secret`); `crypto.randomBytes` for opaque refresh tokens stored in a `RefreshToken` TypeORM entity; TypeORM repositories accessed via `AppDataSource.getRepository(...)`. Password hashing is delegated to `Utilisateur.verifierMotDePasse` on the entity.
