Organized as a barrel-exported library (`src/common/index.ts` re-exports `filters`, `interceptors`, `utils`, `dto`, `middlewares`) consumed by feature modules via the `@common/*` path alias. Internal layering:
- `filters/`: Express error handler (`error.filter.ts`) defines the `AppError` class plus an `Errors` registry of prebuilt instances; `not-found.filter.ts` handles 404s.
- `interceptors/`: factory-based Express interceptors — `audit.interceptor.ts` exposes `createAuditInterceptor(config)` / `genericAuditMiddleware(module, entityType)` that wrap `res.json` to log mutations after response delivery, depending on `@modules/auth/services/audit.service` (a cross-module dependency).
- `middlewares/`: `tenant.middleware.ts` resolves the active `etablissementId` from JWT claims or falls back to a DB lookup via TypeORM's `AppDataSource`, attaching it to `req.etablissementId` for downstream queries.
- `services/`: `redis.service.ts` is a singleton wrapping two `ioredis` clients (`cacheClient` + `subscriberClient`) with retry/backoff, health checks (`isAvailable`), and typed JSON helpers; `cache-metrics.service.ts` exposes cache stats.
- `utils/`: pure helpers — `api-response.util.ts` standardizes `{success,data,message,meta}` responses, `pagination.util.ts` provides cursor/page helpers, `validate-dto.util.ts` wraps class-validator, `logger.util.ts` centralizes Winston/pino usage.
- `dto/` + `examples/`: reusable DTOs and documentation examples for pagination.
- `types/`: ambient Express declarations (`express.d.ts`) augment `Request` with `utilisateur`, `etablissementId`, `util`; `validation-workflow.d.ts` types validation flows.
- `shared/constants/personnel.constants.ts`: module-level enum-like string constants exposed as `as const` with an inferred type.
Dependency direction: `common` depends upward on `@modules/auth` (audit, Role) and `@database/data-source` (tenant resolution); no other module imports back into `common` except through its barrel exports.
