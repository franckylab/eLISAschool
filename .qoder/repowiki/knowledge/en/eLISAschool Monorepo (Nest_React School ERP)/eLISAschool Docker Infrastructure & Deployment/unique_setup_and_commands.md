All operations go through `./deploy.sh <mode> [action]` where `<mode>` is one of `local-dev`, `local-prod`, `cloud-dev`, `cloud-prod` and `[action]` is `up|down|restart|rebuild|status|logs [service]`. On first run the script auto-fills `DB_PASSWORD`, `JWT_SECRET`, `REDIS_PASSWORD`, `ENCRYPTION_KEY`, `PGADMIN_PASSWORD` in the selected `.env.*` file using `openssl rand`; production mode rejects short secrets. Cloud-prod expects `DOMAIN_NAME` set in `.env.cloud` for Let's Encrypt SSL.
