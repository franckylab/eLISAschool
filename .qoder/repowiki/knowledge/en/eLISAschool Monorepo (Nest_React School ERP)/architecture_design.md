The repository is an npm workspaces monorepo (`package.json` declares `backend`, `frontend`, `shared`) where both `backend` and `frontend` consume the same `shared_library` package for domain enums, Zod validators, and configuration registries — this is the single source of truth that keeps API contracts and UI types in sync. The root orchestrates cross-cutting concerns: `npm run dev` launches both servers concurrently, `db:migrate` / `db:seed` delegate to the backend's TypeORM CLI, and `docker:*` scripts drive `docker-compose.dev.yml` / `docker-compose.yml` from the `docker_infra` module to provision PostgreSQL, Redis, pgAdmin, and the two services together. Per-module deployment and maintenance are delegated to shell scripts under `scripts/` (multi-tenant deploy, config refonte, scoring diagnostics), while `VERSION`, `ETAPES-*`, and `INDEX.md` track release state across all children.
