Each subdirectory under `features/<domain>/` is an independent feature package following a fixed internal layout: `components/` (pages + form modals), `hooks/` (React Query–based `use-<entity>.ts` data loaders), `types/<entity>.types.ts`, and an `index.ts` barrel re-exporting them. Cross-feature wiring happens only at the router level — features are imported by name from `@/features/<domain>` and mounted as route handlers; there is no shared feature-to-feature API surface. A few features break the convention (e.g. `auth/`, `apparence/`, `landing/`, `dashboard/`, `system/`) because they own pre-auth or shell-level UIs rather than CRUD screens. Features communicate indirectly via the global Zustand store (`@/stores/auth.store`) for authentication state and the TanStack Router for navigation, keeping each feature decoupled from sibling domains.
