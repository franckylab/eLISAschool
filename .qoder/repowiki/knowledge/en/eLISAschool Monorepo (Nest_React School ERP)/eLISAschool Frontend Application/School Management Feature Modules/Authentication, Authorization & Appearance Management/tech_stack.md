React + TypeScript with TanStack Router (`useRouter`, `useSearch`, `Link`), react-hook-form for form state, Zustand via `useAuthStore` for auth cross-cutting state, TanStack Query (`useQuery`, `useMutation`, `useQueryClient`) for data fetching in the appearance feature, Framer Motion for page animations, lucide-react icons, sonner for toast notifications, and html5-qrcode loaded dynamically inside the QR scanner modal.
