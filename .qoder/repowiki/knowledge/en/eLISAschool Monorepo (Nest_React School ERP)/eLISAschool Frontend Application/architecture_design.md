The frontend is split into three cooperating layers:
- `src/app` (app_shell_and_shared) owns the root `App.tsx`, providers, permission guards, and layout — it is the only place where React context, QueryClient, i18n, and theme stores are instantiated.
- `src/features/<domain>` groups each business area as a self-contained package (`components/`, `hooks/`, `types/`, `index.ts`) that exposes typed hooks and page components but never imports sibling features directly; cross-feature communication goes through shared hooks/stores in `src/hooks` and `src/stores`.
- `src/routes/*` registers every page via TanStack Router's file-based convention, grouping authenticated routes under `_auth.*` barrel files (infrastructure, pedagogical, RH, vie scolaire, etc.) which are then mounted by the shell's route tree.

Cross-cutting concerns enforced at the parent level: all API calls flow through `src/lib/api-client.ts` / `api.ts` (TanStack Query-backed), all user-facing text comes from `locales/{fr,en}/*.json` loaded by `lib/i18n.ts`, and every feature must re-export its public surface from its own `index.ts` barrel so the route barrels can import pages without knowing internal file paths. Build-time assets (favicons, icons) live in `public/` and are generated by scripts in `scripts/`.
