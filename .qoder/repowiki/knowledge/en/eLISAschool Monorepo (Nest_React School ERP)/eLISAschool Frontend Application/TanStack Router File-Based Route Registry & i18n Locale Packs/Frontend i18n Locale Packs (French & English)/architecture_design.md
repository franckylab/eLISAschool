Two parallel language trees under `frontend/src/locales/{fr,en}/` mirror each other one-to-one: every domain file present in `fr/` has an exact counterpart in `en/` (e.g. `auth.json`, `eleves.json`, `common.json`). Each file is a flat JSON object whose top-level keys group related strings (`boutons`, `messages`, `validation`, `dates`, etc.) and whose leaf values are plain translatable strings; some leaves use ICU-style interpolation placeholders like `{{page}}`, `{{total}}`, `{{email}}`. There is no code inside this scope — it is pure data consumed by the application's i18n loader at build/runtime. The naming convention uses kebab-case filenames that map to feature domains (absences, eleves, notes, paie, securite-config, …) plus a shared `common.json` for cross-cutting UI text.
