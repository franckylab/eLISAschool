Routes are declared via TanStack Router's `createFileRoute` in files prefixed `_auth.` so they mount under the shared `/_auth` layout. A single index file (`-_auth.modules-critiques.tsx`) re-exports the three top-level routes (`/utilisateurs`, `/notes`, `/bulletins`) plus a null placeholder at `/modules-critiques` to silence the router warning; child pages live in sibling files (`_auth.utilisateurs.index.tsx`, `_auth.utilisateurs.$id.tsx`, `_auth.notes.index.tsx`, `_auth.notes.$id.tsx`). Each route composes its UI from feature components imported from `@/features/*` and enforces access through `requireModulePermission('utilisateurs'|'notes')` in `beforeLoad`. The `$id` user detail route additionally declares a typed search param `tab` via `validateSearch` defaulting to `'informations'`. Dependency direction is strictly inward: routes → feature components; no cross-route imports beyond the central index.
