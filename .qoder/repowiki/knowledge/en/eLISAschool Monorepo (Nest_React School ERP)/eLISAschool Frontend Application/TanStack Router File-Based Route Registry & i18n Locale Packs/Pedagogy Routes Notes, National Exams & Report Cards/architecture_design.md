Each `.tsx` file is a TanStack `createFileRoute` declaration under the `_auth` layout prefix, mapping one URL segment to a feature page component imported from `@/features/*`. Route files are thin glue only: they register the path (`/_auth/notes/`, `/_auth/notes/$id`, `/_auth/examens-nationaux/`, `/_auth/examens-nationaux/$id`, `/_auth/bulletins`) and attach a `beforeLoad` guard calling `requireModulePermission('notes'|'examens-nationaux'|'bulletins')` before rendering the corresponding `*Page` component. All business logic lives in sibling feature packages under `src/features/`; this module owns no UI or data logic and depends only on the router framework and the permission guard.
