Each `.tsx` file under `frontend/src/routes/_auth.*` is a TanStack Router file-route that maps a URL path to a page component from `@/features/*`. The `_auth.` prefix groups routes behind shared authentication/layout logic defined elsewhere in the router tree. Every route declares a `beforeLoad` hook calling `requireModulePermission('eleves'|'classes'|'programmes')`, enforcing coarse-grained module-level RBAC before any component renders. Route files are thin: they only wire `createFileRoute(path)` → `{ beforeLoad, component }` and import the heavy UI from `@/features/<module>/...`, keeping this scope purely declarative routing with no business logic or data fetching.
