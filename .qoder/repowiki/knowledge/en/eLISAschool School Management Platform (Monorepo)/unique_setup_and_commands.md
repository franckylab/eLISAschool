Workspace root `npm run dev` launches both backend (`nodemon --exec ts-node -r tsconfig-paths/register src/index.ts`) and frontend (`vite --host 0.0.0.0 --port 7001`) concurrently. DB migrations are executed via `npm run db:migrate` (TypeORM `migration:run -d src/database/data-source.ts`), seeds via `npm run db:seed` (runs `src/database/seeds/run-seeds.ts`). Cron jobs are opt-in: set `ENABLE_CRON_JOBS=true` or run in production. `.env` is resolved from three locations before any other import so it must exist at project root.
