Top-level npm workspaces compose three packages: `backend` (Express + TypeORM + PostgreSQL), `frontend` (React 19 + Vite + TanStack Router/Query/Table), and `shared` (Zod schemas, enums, shared types). The backend entry `src/index.ts` bootstraps via `bootstrap()`, initializes TypeORM (`@database/data-source`), preloads permission caches, seeds notification providers, starts cron jobs (notifications, finance, gamification, scoring, sondages, auth, classes) when `ENABLE_CRON_JOBS=true` or production, then calls `createApp()` in `src/app.ts`. That factory wires security middlewares (helmet, CORS with dynamic origin allowlist, rate limiting including a strict 2-min brute-force limiter on `/api/auth/login/register`), gzip compression, static file serving (`/uploads`, `/fonds-catalogue`), Swagger UI at `/api/docs`, the tenant-scoping middleware (`tenantMiddleware`), and mounts every module's Express router under `/api/<module>` — each guarded by `authMiddleware`, `filterByEtablissement()` and an optional `requireModuleActive('<slug>')` gate. Modules live one folder per domain under `backend/src/modules/<domain>/` with a consistent controllers/dto/entities/services layout; cross-cutting concerns sit in `backend/src/common/` (filters, interceptors, middlewares, services like Redis). Database evolution is split between SQL files in `backend/database/migrations/` (TypeORM migration runner) and TS migration scripts in `backend/src/database/migrations/`; seed data lives in `backend/src/database/seeds/`. Frontend follows feature-based routing (`frontend/src/routes/*.tsx`) plus feature folders (`frontend/src/features/*`) sharing state via Zustand stores and API calls through TanStack Query hooks. Docker orchestration is declared in `docker/docker-compose*.yml` with separate dev/prod variants, nginx reverse proxy, pgAdmin, and backup/restore scripts under `docker/scripts/`. A large `scripts/` directory at repo root provides deployment, migration, seeding, verification and test harnesses invoked from the workspace root `package.json`.
