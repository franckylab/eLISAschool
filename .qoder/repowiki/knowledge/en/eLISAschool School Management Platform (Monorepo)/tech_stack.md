Backend: Express 4 + TypeScript 5 + TypeORM 0.3 + PostgreSQL (pg driver); JWT auth (jsonwebtoken) with bcryptjs hashing; Redis (ioredis) as optional cache; Winston logging; Zod validation; Swagger/OpenAPI docs. Frontend: React 19 + Vite 6 + Tailwind v4 + Radix UI primitives + TanStack Router/Query/Table + dnd-kit drag & drop + i18next + Framer Motion + jsPDF/html2canvas. Shared package publishes Zod schemas and enums consumed by both sides.
