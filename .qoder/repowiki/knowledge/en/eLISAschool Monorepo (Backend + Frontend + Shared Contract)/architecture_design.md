Top-level `package.json` declares npm workspaces for three sibling packages: `backend`, `frontend`, and `shared`. The `shared` package is the single source of truth — it publishes enums, Zod validators, API/user types and the module registry that both `backend` and `frontend` import directly. All cross-cutting scripts (`dev`, `build`, `test`, `lint`) are delegated via `--workspace=...` so each child owns its own toolchain while the root orchestrates them. Docker compose files at this level boot the full stack (backend, frontend, Redis) for dev/prod, and DB migrations/seeds are exposed as root commands forwarding into the backend workspace.
