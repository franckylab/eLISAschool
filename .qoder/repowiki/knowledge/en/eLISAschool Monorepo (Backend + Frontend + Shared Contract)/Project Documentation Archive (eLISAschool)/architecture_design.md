Pure Markdown repository with no build step; a single `INDEX.md` acts as the navigation hub linking into 15 thematic sub-directories (`analyses/`, `corrections/`, `implementations/`, `guides/`, `rapports/`, `syntheses/`, `resumes/`, `audits/`, `certifications/`, `checklists/`, `configurations/`, `deploiements/`, `migrations/`, `ameliorations/`, `autres/`) plus root-level reference docs (`technical.md`, `rbac-system.md`, `user-guide.fr.md`). The `autres/` directory is a catch-all for per-session / per-feature scratch notes grouped under `_prefixed_` sub-folders (e.g. `_multi-tenant/`, `_notifications/`, `_phase1/`, `_fix/`, `_seeds/`, `_sessions/`, `_summary/`). Documents follow a French-language convention where filenames encode status and version via prefixes like `ANALYSE-`, `CORRECTION-`, `IMPLEMENTATION-`, `RAPPORT-`, `RESUME-`, `SYNTHESE-`, `MIGRATION-`, `AMELIORATION-`, `AUDIT-`, `DEPLOYMENT-`, `GUIDE-`, `CHECKLIST-`, `CERTIFICATION-`, `MAJ-`, `CONFIGURATION-`. Root files such as `stats.json`, `guards-exemples-implémentation.ts`, and `guide-implémentation-permissions.ts` serve as cross-references to code rather than executable assets.
