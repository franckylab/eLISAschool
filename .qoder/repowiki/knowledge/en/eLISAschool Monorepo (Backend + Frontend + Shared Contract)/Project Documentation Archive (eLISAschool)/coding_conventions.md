- Document filenames are prefixed with their document type in uppercase (ANALYSE-, CORRECTION-, IMPLEMENTATION-, RAPPORT-, RESUME-, SYNTHESE-, MIGRATION-, AMELIORATION-, AUDIT-, DEPLOYMENT-, GUIDE-, CHECKLIST-, CERTIFICATION-, MAJ-, CONFIGURATION-) so that sorting and grep-based discovery work without metadata.
- Obsolete or superseded documents are kept in place but marked with a leading `⚠️ DOCUMENT OBSOLÈTE` banner inside the file and/or a `V2` suffix on the filename, while the active version lives alongside it.
- Cross-cutting topics (multi-tenant, notifications, RBAC, seeds, sessions) are isolated under underscore-prefixed sub-folders inside `autres/` (e.g. `_multi-tenant/`, `_notifications/`, `_seeds/`, `_sessions/`) to keep the top-level flat while grouping related ephemera.
- Root-level index and reference files (`INDEX.md`, `technical.md`, `rbac-system.md`, `user-guide.fr.md`) act as stable entry points that link into the categorized directories rather than being referenced by deep relative paths.
