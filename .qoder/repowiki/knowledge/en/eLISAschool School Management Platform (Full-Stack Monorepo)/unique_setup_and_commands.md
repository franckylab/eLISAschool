Development: `npm run dev` in both `backend/` and `frontend/` directories. Database migrations: `npx typeorm migration:run -d src/database/data-source.ts` or use `scripts/run-migration.ts`. Seed data: `npm run seed` / `seed:rbac` / `seed:demo`. Docker deployment: `docker/compose.yml` with `local.dev` and `cloud.prod` variants. One-shot deploy scripts in root `scripts/` (e.g., `deploy-complete-structure-v2.sh`, `deploy-rbac-v3.sh`). Health check at `/api/health`, API docs at `/api/docs`.
