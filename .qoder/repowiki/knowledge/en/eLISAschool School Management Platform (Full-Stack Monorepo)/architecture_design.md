Monorepo with three main layers: `backend/` (Express + TypeORM REST API), `frontend/` (React + Vite + TanStack Router SPA), and `shared/` (cross-cutting types, enums, validators). The backend uses a modular architecture under `src/modules/<domain>/` where each domain (auth, eleves, finances, personnel, organisation, etc.) encapsulates controllers, services, entities, DTOs, and middlewares. Route registration is centralized in `backend/src/app.ts`, which wires all module controllers behind a common middleware pipeline: helmet → cors → compression → rate-limiting → request logging → tenant scoping (`tenantMiddleware`) → per-route `authMiddleware` + `filterByEtablissement()` + optional `requireModuleActive()`. Database schema evolution is driven by numbered SQL migrations in `backend/database/migrations/` plus TypeORM migrations in `src/database/migrations/`. The frontend follows a feature-sliced layout (`src/features/<feature>/`) with routes generated by TanStack Router. Deployment is containerized via `docker/` with separate Dockerfiles for backend/frontend, docker-compose variants for local/dev/prod, and backup/restore scripts.
