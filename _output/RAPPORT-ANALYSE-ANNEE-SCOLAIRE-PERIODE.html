⚠️ 5. Redondances et Incohérences

Problèmes identifiés classés par sévérité avec impact et recommandation de correction.

5.1 Bugs Critiques

🔴
BUG-1 : Champ enCours redondant
AnneeScolaire.enCours (boolean) est strictement équivalent à statut === 'EN_COURS'. Deux sources de vérité = risque de désynchronisation. Si enCours=true mais statut='OUVERTE', le système est dans un état incohérent.
Recommandation : Supprimer enCours, utiliser uniquement statut.
🔴
BUG-2 : Frontend type mapping divergent
Le frontend AnneeScolaire utilise un enum parallèle (active | inactive | future | archivee) mappé depuis les enums backend. Ce mapping crée un système de types parallèle qui peut diverger. Le module Periode n'a PAS ce mapping.
Recommandation : Aligner le frontend sur les enums backend directement.
🔴
BUG-3 : Pas de cron jobs pour transitions automatiques
Aucune transition automatique ne se produit quand une date de début/fin est atteinte. Un utilisateur doit manuellement activer/clôturer chaque année et période.
Recommandation : Ajouter des cron jobs pour activation/clôture automatique.

5.2 Redondances

#RedondanceSévéritéRecommandation

✅ 8. Verdict et Recommandations

Synthèse finale avec plan d'action priorisé.

🎯 Verdict : Le modèle est correct — la mise en œuvre nécessite des corrections

L'architecture AnneeScolaire → Periode (racine → enfants) est déjà en place et valide. Elle correspond aux standards internationaux (OneRoster, PowerSchool, Infinite Campus). Les corrections nécessaires sont des nettoyages de cohérence, pas une refonte architecturale.

  • Supprimer le champ enCours redondant (source unique = statut)
  • Aligner le frontend type mapping sur les enums backend
  • Ajouter des cron jobs pour transitions automatiques
  • Conserver la double FK dénormalisée (optimisation intentionnelle)
  • Conserver les deux modules séparés (complémentaires, pas redondants)

🚀 9. Plan de Migration (Direct et Brutal)

Plan d'exécution sans intermédiaire — migration directe en une seule passe.

Phase 1 — Suppression enCours (P0)

Backend : Supprimer colonne enCours de l'entité. Remplacer tous les usages par statut === StatutAnneeScolaire.EN_COURS. Ajouter getter get isEnCours() dérivé.
Frontend : Supprimer toute référence à enCours dans les types, hooks, composants.
Migration SQL : ALTER TABLE annees_scolaires DROP COLUMN IF EXISTS "enCours"
Impact : ~15 fichiers backend, ~5 fichiers frontend

Phase 2 — Alignement Frontend Types (P0)

Frontend : Supprimer StatutAnneeScolaireFrontend (active/inactive/future/archivee). Utiliser directement StatutAnneeScolaire du backend (OUVERTE/EN_COURS/EN_ATTENTE_CLOTURE/CLOTUREE).
Composants : Mettre à jour annees-scolaires-page.tsx et annee-scolaire-detail-page.tsx pour utiliser les enums backend.
Impact : ~4 fichiers frontend

Phase 3 — Cron Auto-Transition (P1)

Backend : Créer cronAnneesScolaires() dans annees-scolaires/cron-jobs.ts.
Logique : Quotidien à 00h05 — pour chaque établissement : si dateDebut <= today && dateFin >= today && statut=OUVERTE → activer(). Si dateFin < today && statut=EN_COURS → cloturer().
Config : Paramètre annees_scolaires.transition_auto (booléen, défaut false).
Impact : 2 fichiers backend, 1 paramètre config

Phase 4 — Interface Cloturable (P1)

Backend : Créer shared/src/interfaces/cloturable.interface.ts avec méthodes cloturer(), reouvrir(), verifierPreCloture().
Implémentation : AnneeScolaire et Periode implémentent cette interface. Logique commune extraite (checks notes, bulletins, validation workflow).
Impact : 3 fichiers backend (interface + 2 services refactorés)

Phase 5 — Nettoyage i18n + Getter Déprécié (P2)

Frontend : Créer frontend/src/locales/fr/periodes.json + en/periodes.json. Extraire les clés de common.json vers ce namespace.
Backend : Supprimer get cloturee() de l'entité AnneeScolaire. Remplacer par statut === CLOTUREE inline.
Impact : 4 fichiers frontend, 1 fichier backend

💻 10. Code SQL de Migration

Migration 220 — Suppression enCours + Nettoyage AnneeScolaire

-- ============================================================
-- Migration 220 : Consolidation temporelle AnneeScolaire/Periode
-- eLISAschool — Suppression enCours redondant + alignement
-- Idempotent — Safe production
-- ============================================================

-- 1. Supprimer le champ enCours redondant
-- (source unique de vérité = statut)
ALTER TABLE annees_scolaires
  DROP COLUMN IF EXISTS "enCours";

-- 2. Index de performance pour la recherche de l'année active
CREATE INDEX IF NOT EXISTS idx_annees_scolaires_etablissement_statut
  ON annees_scolaires ("etablissementId", statut)
  WHERE statut = 'EN_COURS';

-- 3. Vérification cohérence post-migration
-- Aucune année ne devrait avoir statut incohérent
DO $$
DECLARE
  incoherent_count INT;
BEGIN
  SELECT COUNT(*) INTO incoherent_count
  FROM annees_scolaires
  WHERE statut NOT IN ('OUVERTE', 'EN_COURS', 'EN_ATTENTE_CLOTURE', 'CLOTUREE');

  IF incoherent_count > 0 THEN
    RAISE EXCEPTION ' Cohérence rompue : % années avec statut invalide', incoherent_count;
  END IF;

  -- Vérifier une seule année EN_COURS par établissement
  PERFORM "etablissementId"
  FROM annees_scolaires
  WHERE statut = 'EN_COURS'
  GROUP BY "etablissementId"
  HAVING COUNT(*) > 1;

  IF FOUND THEN
    RAISE WARNING 'Plusieurs années EN_COURS dans le même établissement détectées';
  END IF;
END $$;

Cron Job — Auto-Transition

// backend/src/modules/annees-scolaires/cron-jobs.ts
import cron from 'node-cron';
import { AppDataSource } from '@database/data-source';
import { AnneeScolaire, StatutAnneeScolaire } from './entities';
import { configurationService } from '@modules/configuration/services/configuration.service';
import { logger } from '@common/utils/logger.util';

/**
 * Cron : Transition automatique des années scolaires
 * - Activation auto à dateDebut (si transition_auto = true)
 * - Clôture auto à dateFin+1 (si cloture_auto = true)
 * Schedule : quotidien 00h05 (Africa/Douala)
 */
export async function cronTransitionsAnneesScolaires(): Promise<void> {
  const repo = AppDataSource.getRepository(AnneeScolaire);
  const today = new Date();
  today.setHours(0, 0, 0, 0);

  // Récupérer tous les établissements avec des années en transition
  const etablissements = await repo
    .createQueryBuilder('as')
    .select('DISTINCT as.etablissementId', 'etabId')
    .getRawMany();

  for (const { etabId } of etablissements) {
    const transitionAuto = await configurationService.getParametre(
      'annees_scolaires.transition_auto', etabId
    );
    const clotureAuto = await configurationService.getParametre(
      'annees_scolaires.cloture_auto', etabId
    );

    // Auto-activation : dateDebut <= today && statut = OUVERTE
    if (transitionAuto) {
      const aActiver = await repo.findOne({
        where: {
          etablissementId: etabId,
          statut: StatutAnneeScolaire.OUVERTE,
        },
        order: { dateDebut: 'DESC' },
      });

      if (aActiver && new Date(aActiver.dateDebut) <= today) {
        // Désactiver l'année en cours actuelle
        await repo.update(
          { etablissementId: etabId, statut: StatutAnneeScolaire.EN_COURS },
          { statut: StatutAnneeScolaire.OUVERTE }
        );
        // Activer la nouvelle
        aActiver.statut = StatutAnneeScolaire.EN_COURS;
        await repo.save(aActiver);
        logger.info(`[Cron] Année ${aActiver.libelle} auto-activée (étab: ${etabId})`);
      }
    }

    // Auto-clôture : dateFin < today && statut = EN_COURS
    if (clotureAuto) {
      const aCloturer = await repo.findOne({
        where: {
          etablissementId: etabId,
          statut: StatutAnneeScolaire.EN_COURS,
        },
      });

      if (aCloturer && new Date(aCloturer.dateFin) < today) {
        aCloturer.statut = StatutAnneeScolaire.CLOTUREE;
        await repo.save(aCloturer);
        logger.info(`[Cron] Année ${aCloturer.libelle} auto-cloturée (étab: ${etabId})`);
      }
    }
  }
}

export function initAnneesScolairesCronJobs(): void {
  // Quotidien à 00h05 (Africa/Douala)
  cron.schedule('5 0 * * *', async () => {
    try {
      await cronTransitionsAnneesScolaires();
    } catch (error) {
      logger.error('[Cron] Erreur transition années scolaires', error);
    }
  }, { timezone: 'Africa/Douala' });

  logger.info('[Cron] Cron transitions années scolaires initialisé (00h05 daily)');
}
