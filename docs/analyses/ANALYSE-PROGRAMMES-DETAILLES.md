## 1. Structure APC — Approche Par Compétences

### Philosophie Générale
- **Entrée** : Situations de vie (contextes réels et signifiants)
- **Évaluation** : Situations-problèmes (mobilisation des ressources)
- **Intégration** : Savoirs + Savoir-faire + Savoir-être
- **Progression** : Par compétences de production (et non par contenus)

### Structure Type d'un Programme APC

```
Programme
├── Module (thème fédérateur)
│   ├── Chapitre (unité d'apprentissage)
│   │   ├── Leçon 1 (séance d'apprentissage)
│   │   │   ├── Objectif pédagogique
│   │   │   ├── Compétence visée
│   │   │   ├── Prérequis
│   │   │   ├── Contenu (savoirs)
│   │   │   ├── Activités (savoir-faire)
│   │   │   └── Évaluation
│   │   ├── Leçon 2
│   │   └── ...
│   ├── Situation-problème d'intégration
│   └── Évaluation formative
└── ...
```

### Vocabulaire Clé

| Terme | Définition |
|-------|-----------|
| **Compétence** | Aptitude à mobiliser des ressources pour résoudre une situation-problème |
| **Ressource** | Savoir, savoir-faire, savoir-être mobilisable |
| **Situation-problème** | Contexte signifiant nécessitant la mobilisation de compétences |
| **Séquence didactique** | Ensemble de séances organisées pour atteindre un objectif |
| **Progression harmonisée** | Répartition nationale des contenus sur l'année scolaire |

### Structure de Données Recommandée

```typescript
// Table: ProgrammePedagogique (curriculum intemporel)
interface ProgrammePedagogique {
  id: string;
  matiereId: string;              // FK vers Matiere
  niveauId: string;               // FK vers ClasseAnnee
  titre: string;                  // Ex: "Mathématiques 6ème — Programme APC 2023"
  description: string;            // Description générale du programme
  competenceGlobale: string;      // Compétence globale visée
  approche: 'APC' | 'TRADITIONNEL' | 'MIXTE';
  source: 'MINESEC_2023' | 'MINEDUB_2023' | 'MANUEL';
  anneeProgramme: string;         // Ex: '2023-2024'
  etablissementId: string;
}

// Table: ChapitreProgramme (découpage du programme)
interface ChapitreProgramme {
  id: string;
  programmeId: string;            // FK vers ProgrammePedagogique
  moduleId?: string;              // FK vers Module (regroupement optionnel)
  numero: number;                 // Ordre dans le programme (1, 2, 3...)
  titre: string;                  // Ex: "Nombres décimaux et fractions"
  description: string;            // Description détaillée
  objectifs: string[];            // Liste des objectifs pédagogiques
  competences: string[];          // Liste des compétences visées
  prerequis: string[];            // Liste des prérequis
  contenus: string[];             // Liste des contenus (savoirs)
  activites: string[];            // Liste des activités proposées
  evaluation: string;             // Modalités d'évaluation
  periodeDebut: string;           // Ex: "Septembre"
  periodeFin: string;             // Ex: "Décembre"
  volumeHoraire: number;          // En minutes (estimé)
  ressources: string[];           // Ressources pédagogiques (liens, manuels)
}

// Table: ModuleProgramme (regroupement de chapitres — optionnel)
interface ModuleProgramme {
  id: string;
  programmeId: string;            // FK vers ProgrammePedagogique
  numero: number;                 // Ordre dans le programme
  titre: string;                  // Ex: "Module 1 : Nombres décimaux et fractions"
  description: string;            // Description du module
  objectifFederalteur: string;    // Objectif fédérateur du module
  competencesModule: string[];    // Compétences spécifiques au module
}
```

## 📌 Prochaines Étapes pour eLISAschool

### 1. Création des Seeds Programmes

```typescript
// Script de seed pour insérer les programmes et chapitres
async function seedProgrammes() {
  // 1. Créer les programmes (un par matière/niveau)
  const programmes = [
    programmeMaths6eme,
    programmeFrancais6eme,
    // ... autres programmes
  ];
  
  for (const prog of programmes) {
    await ProgrammePedagogique.create(prog);
  }
  
  // 2. Créer les modules (optionnel)
  const modules = [...modulesMaths6eme, /* ... */];
  for (const mod of modules) {
    await ModuleProgramme.create(mod);
  }
  
  // 3. Créer les chapitres
  const chapitres = [...chapitresMaths6eme, ...chapitresFrancais6eme, /* ... */];
  for (const chap of chapitres) {
    await ChapitreProgramme.create(chap);
  }
}
```

// Lier les programmes aux affectations de matières
const affectationMatiere = await AffectationMatiere.findOne({

await affectationMatiere.save();
