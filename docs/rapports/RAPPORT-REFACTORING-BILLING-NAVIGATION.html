3.2 Decisions terminologiques validées

🟢

BASE (etait CRITIQUE)

Modules fondamentaux toujours disponibles, non facturables. Le backend a deja migre. Le frontend doit suivre.

🔵

PREMIUM (conserve)

Modules inclus dans les plans payants. Le terme est universellement compris dans l'industrie SaaS.

🟠

ADDON (conserve)

Modules souscriptibles separement. Correspond au concept Stripe "Add-ons" et Orb "Add-ons".

🟣

Marche / Marketplace

Remplace "Modules" comme label de menu. Evoque un lieu d'exploration et de souscription, pas une liste technique.

8.1 Patterns de navigation — Leaders SaaS

Editeur Section Billing Sous-menus Points cles

8.2 Recommandations pour eLISAschool

📐

3-4 plans maximum

Eviter la fatigue de decision. Stripe recommande 3 plans (Starter/Growth/Enterprise). eLISAschool : Gratuit/Standard/Premium/Enterprise.

📊

Usage dashboards temps reel

Schematic et Orb montrent des jauges en temps reel avec seuils colores. Implementer des progress bars animees avec alertes visuelles.

🧮

Simulateur integre

Paddle et Chargebee ont des calculateurs de prix interactifs. Le slider "nombre d'eleves" → prix est deja implemente, le rendre plus visible.

🛒

Marketplace = App Store

Stripe App Marketplace : cards avec descriptions, screenshots, pricing. Chaque module = une "app" avec fiche detaillee.
